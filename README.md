# 학부모 연락처 3D

전화번호부(연락처)와 문자 메시지를 분석해서, **학생 이름을 검색하면 학부모님 전화번호를 3D 카드로 보여주는** 웹 앱입니다.

- 설치 없이 브라우저에서 실행 (휴대폰·PC 모두)
- 모든 데이터는 **기기 안에서만 처리**되며 서버로 전송되지 않습니다
- 3D 카드를 누르면 바로 📞 전화 / 💬 문자 / 📋 복사

## 어떻게 찾나요?

| 데이터 | 예시 | 판정 |
|---|---|---|
| 연락처 이름 | `김민수 어머니`, `민수아빠`, `이서연(모)`, `박지호 학부모`, `장하린 母` | 어머니 / 아버지 / 학부모 / 보호자 |
| 받은 문자 | "선생님, **최유진 엄마**입니다" | 보낸 번호 = 학부모 |
| 보낸 문자 | "**민수 어머님**, 상담 일정…" | 받는 번호 = 학부모 |

성을 뺀 이름(`민수`)과 `예린이 엄마` 같은 표현도 인식하며, 여러 근거가 겹칠수록 신뢰도가 올라갑니다.

## 데이터 불러오기

브라우저는 보안상 휴대폰의 연락처/문자함을 마음대로 읽을 수 없어서, 아래 방법으로 불러옵니다.

- **연락처**
  - 안드로이드 크롬(HTTPS): `휴대폰 연락처에서 바로 가져오기` 버튼 (Contact Picker API)
  - 그 외: 연락처 앱 → 내보내기 → `.vcf` 파일, 또는 구글 주소록 `.csv`
- **문자**
  - 안드로이드: *SMS Backup & Restore* 앱으로 만든 `.xml` 백업 파일
  - 또는 문자 내용을 복사해서 붙여넣기 (번호가 나온 줄 다음 내용을 그 번호의 문자로 인식)

`📥 데이터 → 🧪 샘플로 체험`으로 가상 데이터로 바로 써볼 수 있고, `samples/` 폴더에 예시 파일이 있습니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 휴대폰에서 쓰고 연락처 직접 가져오기까지 사용하려면 HTTPS가 필요하므로
GitHub Pages(Settings → Pages → 이 브랜치 / root)로 배포하는 것을 추천합니다.

## 구성

- `index.html`, `style.css`, `app.js` — 앱 (파서, 검색, three.js 3D 장면)
- `vendor/three.min.js` — three.js (MIT, 오프라인에서도 동작하도록 포함)
- `samples/` — 예시 연락처(.vcf)와 문자 백업(.xml) — 모두 가상의 이름·번호
